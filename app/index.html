No games yet

This app comes without games. Add .p8.png or .p8 carts in one of these ways, one folder per game (the folder name is the title):

  • USB drive: a PICO8 folder at the root of the drive, such as PICO8/Celeste/celeste.p8.png. Plug it into the TV; it is read automatically.
  • TV Documents: the same PICO8 folder in the TV's Documents folder.
  • A PC on the same network: run python3 tools/cart_server.py <folder> from this app's source, then press Home and enter the address it prints under "PC with carts".

Games appear here as soon as they are found.
